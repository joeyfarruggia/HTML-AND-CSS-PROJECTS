# HTML & CSS Projects

A collection of front-end projects and exercises created while developing my HTML, CSS, responsive-design, and user-interface skills.

The projects range from foundational HTML/CSS exercises to larger multi-section websites incorporating responsive layouts, Bootstrap, JavaScript, forms, images, animations, and interactive styling.

## Featured Projects

### 🎬 Academy Cinemas

A responsive cinema website built with HTML, CSS, Bootstrap, JavaScript, and supporting image assets.

The project provided hands-on experience with:

- Responsive page layouts
- Bootstrap components and styling
- Multi-section page design
- Navigation
- Movie listings
- Images and visual content
- CSS customization
- JavaScript integration

[View Academy Cinemas](Academy-Cinemas/)

---

### 🍽️ Simple Recipes

A recipe website combining HTML, CSS, JavaScript, and image assets.

The project focuses heavily on visual presentation and interactive CSS effects while organizing larger amounts of content into a structured web page.

It includes:

- Custom CSS
- Image-based content
- Hover effects
- Layout and spacing
- Typography
- JavaScript
- Structured recipe content

[View Simple Recipes](Simple-Recipes/)

---

### 🐾 The Pet Shop

A multi-page pet-shop website created while developing foundational HTML and CSS skills.

The project contains a main page, separate contact page, custom CSS, images, and favicon assets.

It demonstrates:

- Multi-page website structure
- Navigation
- CSS styling
- Image integration
- Contact-page design
- Reusable visual styling

[View The Pet Shop](The-Pet-Shop-Website/)

---

### 💻 Portfolio Website — Course Project

A portfolio-style website created as a larger front-end course project.

This project brought together concepts from earlier HTML and CSS exercises and includes separate directories for CSS, JavaScript, and image assets.

It represents an earlier stage of my front-end development and is separate from my current software-development portfolio.

[View Portfolio Course Project](Portfolio-Website/)

## Running the Projects

Clone the repository:

```bash
git clone https://github.com/joeyfarruggia/html-css-projects.git
cd html-css-projects
```

Most projects can be viewed by opening their main HTML file directly in a web browser.

For example:

```text
Academy-Cinemas/index.html
Simple-Recipes/index.html
The-Pet-Shop-Website/index.html
Portfolio-Website/index.html
```
